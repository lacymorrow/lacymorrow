## About

`lacy` is a shell plugin that makes your terminal AI-native. Type a shell command and it runs. Type a question or task description and it goes to an AI agent (Claude, Gemini, Codex, or opencode). No special prefixes or modes. It figures out intent on its own.

The plugin shells out to `lash` as a binary with zero npm dependency, so shell startup stays fast.

**Supported shells:** zsh · bash
